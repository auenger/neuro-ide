# Neuro-IDE

Neuro-IDE 是一个基于 **Electron**、**React** 和 **TypeScript** 构建的现代 AI 辅助集成开发环境（IDE）。它采用了独特的三栏布局设计，旨在无缝集成多角色终端会话、专业代码编辑器和实时 Markdown 预览，为开发者提供全新的编程体验。

## 🚀 项目概述

Neuro-IDE 致力于通过将基于角色的 AI 工作流直接嵌入 IDE，重新定义编码体验。它为不同的角色（如架构师、前端、后端）提供上下文感知的终端，允许开发者在保持状态的同时轻松切换上下文。

### ✅ 已实现的核心功能

#### 1. 核心系统 (终端架构)

- **稳健的 Electron 架构**: 基于类型安全的 Electron + Vite + React 基础构建。
- **原生终端集成**: 由 `node-pty` 驱动，实现真正的系统进程管理。
- **高性能渲染**: 使用 `xterm.js` 提供流畅、原生般的终端体验。
- **多角色会话**: 支持多个持久化终端会话（如架构师、前端、后端），拥有独立的命令历史和状态。
- **多终端实例**: 每个角色可以拥有多个终端标签页，支持并行执行命令。
- **终端管理功能**:
  - 每个角色可创建无限个终端实例
  - 通过直观的标签页界面切换终端
  - 支持内联编辑重命名终端
  - 快速重启和清屏功能
  - 可关闭单个终端（每个角色至少保留一个）
- **跨平台支持**: 完全兼容 Windows、macOS 和 Linux
- **复制粘贴支持**: 支持右键粘贴和键盘快捷键（Ctrl/Cmd+C/V）

#### 2. 界面交互 (布局与设计)

- **灵活的三栏布局**: 可调节的侧边栏、主面板（Markdown/聊天）和舞台面板（代码编辑器）。
- **专业 UI 设计**: 采用类 VS Code 的暗色主题，配合 SVG 图标，界面简洁美观。
- **Markdown 工作室**: 集成双栏 Markdown 编辑器，支持 GitHub 风格的实时预览。
- **可折叠面板**: Markdown 编辑器可折叠以最大化终端空间。
- **终端标签页**: 简洁的标签页界面管理多个终端实例。

#### 3. AI 引擎 (Claude Code 集成)

- **Claude 历史浏览器**: 全面集成 Claude Code 历史记录。
  - **项目自动检测**: 自动识别当前工作区相关的 Claude 项目。
  - **对话列表**: 侧边栏可折叠部分，快速访问最近的 AI 对话。
  - **增量同步**: 一键将最新的 Claude 会话同步至工作区。
  - **数据分析**: 可视化 Token 使用情况（输入、输出、缓存）及已编辑文件追踪。
  - **覆盖层视图**: 无需离开当前工作区即可深入查看完整的项目历史。
  - **离线持久化**: 可选将历史数据存储在 `.neuro` 文件夹中，实现极速加载。

#### 4. 工作区与配置管理

- **配置管理器**: 用于管理所有 IDE 设置的集中式 GUI 界面。
  - **角色编辑器**: 为每个角色配置默认命令、图标和环境。
  - **工作区设置**: 针对每个项目设置忽略模式、自动同步偏好和终端行为。
- **工作目录管理**: 支持打开和切换本地文件夹，终端会话会自动迁移至新目录。
- **最近工作空间**: 通过原生系统菜单或工作区选择器快速访问最近打开的 8 个文件夹。
- **递归文件树**: 支持无限层级文件夹、自动排序，并通过 `chokidar` 实现实时文件监听。
- **全局搜索**: 强大的跨文件搜索能力，优先匹配文件名。
- **Monaco 编辑器**: 集成全功能代码编辑器 (VS Code 核心)，支持语法高亮和高级编辑功能。
- **星标文件**: 快速访问常用文件和文件夹，支持拖拽排序。
- **文件变更追踪**: 自动追踪修改的文件，方便 review 和添加标。
- **终端活跃度监控**: 针对终端输出活动和空闲状态的智能通知。

## 🛠 技术栈

- **核心框架**: Electron, React, TypeScript
- **构建工具**: Vite, Electron-Vite
- **终端组件**: node-pty, xterm.js, xterm-addon-fit
- **编辑器组件**: @monaco-editor/react
- **状态管理**: Zustand
- **文件系统**: Node.js fs, chokidar

## 🚀 快速开始

### 环境依赖

- Node.js (推荐 v18+)
- npm 或 yarn

### 安装

```bash
$ npm install
```

### 开发模式

启动带有热重载的开发环境:

```bash
$ npm run dev
```

### 打包构建

构建生产环境应用:

```bash
# macOS
$ npm run build:mac

# Windows
$ npm run build:win

# Linux
$ npm run build:linux
```
